# Fall guys Bot

A bot for automating Fall Guys gameplay.

## Features

- Automatically handles in-game actions
- Multiple resolution support (1080p and 720p)
- Event mode support
- Graphical user interface for easy operation

## Usage

1. Run the program
2. Select mode (Stable, Beta, or Event)
3. Click Start to begin the bot
4. Use Stop to halt the bot at any time

## Requirements

- Python 3
- Required libraries: pyautogui, opencv-python, psutil, tkinter
